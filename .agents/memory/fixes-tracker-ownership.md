**Why:** The user clarified that the allowance tracker is not the tracker for the fixes effort and requested a separate main tracker with the same discipline.

**How to apply:** Read `fixes/AGENT_PRE_PROMPT.md`, `fixes/PLAN.md`, and `fixes/TRACKER.md` before fixes work. Use the allowance tracker only as the read-only process reference described there.
