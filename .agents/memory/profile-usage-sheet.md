---
name: Profile usage sheet
description: The reference-driven layout for the profile privacy and usage summary sheet.
---

The profile usage sheet is a full-height dark bottom sheet with a rounded top edge, a compact sparkle title row, and a flat scrollable list. Each row has a lavender icon tile, a bold field label, muted one-line explanation, and an indigo value aligned to the right.

**Why:** The supplied reference prioritizes scanning the profile fields and their current values; a privacy paragraph, bordered list card, and bottom confirmation button consume space without serving that layout.

**How to apply:** Keep the list ordered as Daily focus goal, Wake-up time, Occupation, Focus goals, Name, Sleep time, Best focus time, Ideal focus block, Break style, Distraction triggers, Motivation style, and Weekly review day. Preserve live values from the profile state.
