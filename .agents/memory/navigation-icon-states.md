---
name: Navigation icon states
description: The Focus and Defense tab icon visual rules for the Kotlin app.
---

Use the same compact, monochrome outlined timer and selected/unselected tint behavior as the other navigation icons for Focus. Keep Defense's filled shield silhouette in both states; its checkmark is negative space, and selection is shown through tint rather than swapping to an outline shield.

**Why:** The custom gradient timer looked oversized and permanently emphasized, while the outlined Defense variant became too thin at navigation size. The user asked that neither tab stand out from the rest of the navigation.

**How to apply:** Preserve these visual rules in the bottom navigation and the side drawer. The larger branded timer illustration inside the Focus screen is separate from the navigation icon.
