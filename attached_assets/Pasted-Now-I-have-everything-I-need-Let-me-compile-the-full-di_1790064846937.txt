### Bug 1 — `ACTION_TASK_ENDED` is sent but never received (Room session never ends)

**This is the root cause of the "timer stuck on overdue" problem.**

In `ForegroundTaskService.tickRunnable`, when the task's end time hits zero:
```kotlin
clearFocusActive()     // only writes focus_active=false to SharedPrefs
sendBroadcast(Intent(ACTION_TASK_ENDED)...)
triggerTaskAlarm(...)
goIdle()               // only clears service in-memory state
```

`clearFocusActive()` and `goIdle()` touch SharedPrefs and service memory — but **nobody updates Room**. I grepped every file in the zip: `ACTION_TASK_ENDED` is defined once, broadcast in two places, and **received nowhere**. No component — not `FocusSessionViewModel`, not `MainActivity`, nobody — registers a `BroadcastReceiver` for it.

The consequence:
- `focusSessionDao.observeActiveSession()` still returns the session (its `ended_at` is still null in Room)
- `FocusSessionViewModel`'s collect loop re-emits it → `_focusSession.value` stays non-null
- `isFocusing = session?.isActive == true` → **true forever**
- The Focus screen's timer, "Focus Mode Active" header, and Stop/Done/Extend buttons all remain visible and the timer keeps counting into overdue

### Bug 2 — `keepFocusActiveUntilTaskEnd` defaults to `true`, so Done never calls `stopFocusMode()`

### Immediate escape

**Use the "Stop Focus" button**, not Done. `requestStop()` → (no-PIN path) shows a confirmation → `stopFocusModeAwait()` → properly ends the Room session, clears SharedPrefs, stops the service, sets `_focusSession.value = null`. That's the only button in the current codebase that correctly calls the full shutdown sequence regardless of task status or `keepFocusActiveUntilTaskEnd`.

Done/✓/Skip are all gated by settings or are no-ops on a completed task. "Stop Focus" is not.

### Fixes

**Fix 1 — Handle `ACTION_TASK_ENDED` to end the Room session**

In `FocusSessionViewModel.init`, register a receiver:
```kotlin
private val taskEndedReceiver = object : BroadcastReceiver() {
    override fun onReceive(ctx: Context, intent: Intent) {
        viewModelScope.launch {
            focusSessionRepository.getActiveFocusSession()?.let { session ->
                focusSessionRepository.endFocusSession(session.taskId)
            }
            _focusSession.value = null
        }
    }
}
// init: context.registerReceiver(taskEndedReceiver, IntentFilter(ForegroundTaskService.ACTION_TASK_ENDED), RECEIVER_NOT_EXPORTED)
// onCleared: context.unregisterReceiver(taskEndedReceiver)
```
This is the most important fix. It closes the gap between service going idle and Room/UI knowing about it.

**Fix 2 — Filter completed tasks from `activeTask` in HomeScreen**

```kotlin
val activeTask = remember(todayTasks, focusSession) {
    todayTasks
        .filter { it.status !in setOf("completed", "skipped") }   // ← add this
        .firstOrNull { it.id == focusSession?.taskId }
        ?: todayTasks.firstOrNull(Task::isRunningNow)
}
```
Once the task is complete, the banner disappears from Schedule even if the session is still technically alive.

**Fix 3 — In overdue state, Done should always stop focus regardless of `keepFocusActiveUntilTaskEnd`**

In the completion confirmation handler in FocusScreen:
```kotlin
onClick = {
    taskViewModel.completeTask(task.id)
    if (!settings.keepFocusActiveUntilTaskEnd || overdue) {  // ← add || overdue
        focusSessionViewModel.stopFocusMode()
    }
    showCompleteConfirmation = false
}
```
Same logic in HomeScreen's `onComplete` for the banner. `keepFocusActiveUntilTaskEnd` only makes sense when you mark a task done early — past end time it makes no sense.

**Fix 4 — Guard the overdue timer label by task status**

In `FocusTaskPanel`, wrap the overdue display:
```kotlin
val displayOverdue = overdue && task.status !in setOf("completed", "skipped")

text = task.remainingLabel(now)           // still shows, but:
text = if (displayOverdue) "overdue" else "remaining"
```
Or, simpler: don't render the overdue state at all for completed tasks.
