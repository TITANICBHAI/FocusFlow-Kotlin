# FocusFlow old import/export source archive — file purposes

This is a filtered, historical source snapshot from commit `5cd3fd017f05b500084e0ba21b80355bf5366353` in `TITANICBHAI/FocusFlow-Kotlin`.
The archive keeps the 18 non-test Kotlin source files and restores their original repository directory paths. It removes 15 Kotlin test files and 2 test-runner shell scripts.

> These are historical sources from the specified commit; they are not guaranteed to compile against the current main branch on their own.

## Included files

| File | Purpose |
|---|---|
| `BackupEnvelopeV1.kt` (`app/src/main/java/com/tbtechs/focusflow/data/backup/BackupEnvelopeV1.kt`) | Defines the V1 backup envelope and task data models, parse results, and bounded/validated JSON parsing for imported backup files. |
| `BackupV1Exporter.kt` (`app/src/main/java/com/tbtechs/focusflow/data/backup/BackupV1Exporter.kt`) | Serializes task and settings data into the FocusFlowBackupV1 JSON wire format used when exporting a backup. |
| `BackupManager.kt` (`app/src/main/java/com/tbtechs/focusflow/data/repository/BackupManager.kt`) | Core backup/import repository layer: maps task and settings data to/from backup payloads, validates input, and reports import/restore outcomes while preserving raw JSON fields for compatibility. |
| `AndroidRestorePhaseActions.kt` (`app/src/main/java/com/tbtechs/focusflow/data/restore/AndroidRestorePhaseActions.kt`) | Connects restore phases to Android app persistence and derived-state work, including rebuilding alarm-related state during restore. |
| `RestoreCoordinator.kt` (`app/src/main/java/com/tbtechs/focusflow/data/restore/RestoreCoordinator.kt`) | Coordinates pending-import admission and restore previews/plans, and launches an admitted restore in application scope so UI cancellation does not cancel it. |
| `RestorePlan.kt` (`app/src/main/java/com/tbtechs/focusflow/data/restore/RestorePlan.kt`) | Defines restore modes/phases, counts, journal/conflict models, and logic for planning task merge/replace operations and detecting duplicate IDs or conflicts. |

| `RestoreStores.kt` (`app/src/main/java/com/tbtechs/focusflow/data/restore/RestoreStores.kt`) | Encodes/decodes restore journals and stores pending-import records and journal files with bounded reads and atomic file writes. |
| `BackupCoordinator.kt` (`app/src/main/java/com/tbtechs/focusflow/ui/backup/BackupCoordinator.kt`) | UI/activity bridge for backup file pickers and repository operations; centralizes import/export callbacks rather than duplicating the flow across screens. |
| `ImportConfirmScreen.kt` (`app/src/main/java/com/tbtechs/focusflow/ui/backup/ImportConfirmScreen.kt`) | Jetpack Compose import-review and confirmation UI, including import preview, selected sections, loading/error states, and result details. |
| `ImportProtectionPolicy.kt` (`app/src/main/java/com/tbtechs/focusflow/ui/backup/ImportProtectionPolicy.kt`) | Compares current and imported protection settings to decide whether importing would remove protected controls and therefore require PIN protection. |
| `ImportProtectionSummaryPolicy.kt` (`app/src/main/java/com/tbtechs/focusflow/ui/backup/ImportProtectionSummaryPolicy.kt`) | Builds the post-import protection summary, describing imported categories as active or inactive based on item count, feature state, and permission availability. |
| `RestoreProgressDisplay.kt` (`app/src/main/java/com/tbtechs/focusflow/ui/backup/RestoreProgressDisplay.kt`) | Maps internal restore phases/states to user-facing progress messages and step counts for the import UI. |
| `VpnImportPolicy.kt` (`app/src/main/java/com/tbtechs/focusflow/ui/backup/VpnImportPolicy.kt`) | Determines when VPN/network-block import consent or notices are needed and whether imported VPN blocking may be activated after permission checks. |
| `FocusFlowAgentGuide.kt` (`app/src/main/java/com/tbtechs/focusflow/ui/settings/FocusFlowAgentGuide.kt`) | Contains a self-contained prompt/instructions for generating task-only .focusflow V1 backup files, with explicit constraints around dates, tasks, settings, and device-only state. |
| `FocusFlowFileGuideScreen.kt` (`app/src/main/java/com/tbtechs/focusflow/ui/settings/FocusFlowFileGuideScreen.kt`) | Jetpack Compose screen that presents the FocusFlow file-format guide in Settings. |
| `FocusFlowFormatGuideContent.kt` (`app/src/main/java/com/tbtechs/focusflow/ui/settings/FocusFlowFormatGuideContent.kt`) | Composable presentation/layout of the .focusflow format guide: sections, field explanations, callouts, and examples. |
| `FocusFlowFormatGuideData.kt` (`app/src/main/java/com/tbtechs/focusflow/ui/settings/FocusFlowFormatGuideData.kt`) | Guide copy and structured field/reference data describing the .focusflow format, task fields, portable settings, and import semantics. |
