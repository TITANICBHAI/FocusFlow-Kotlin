FOCUSFLOW UI REDESIGN — FULL SCREEN IMPLEMENTATION

The supplied reference screenshots are the visual and interaction source of
truth.

There are FIVE reference screens:

1. Schedule empty state
2. New Task
3. Schedule populated
4. Task Details
5. Edit Task

The current Kotlin/Jetpack Compose implementation has simplified/"cheap"
versions of these screens.

The task is NOT to make minor cosmetic adjustments.

Reimplement the affected screens so they have the same visual hierarchy,
spacing, component treatment, typography, colors, controls, states, and
interaction model as the reference screenshots.

IMPORTANT:
These are real application screens. Do NOT hardcode screenshot content.
Continue using the existing database/models/ViewModels/navigation/state.

Preserve all existing business logic unless it is demonstrably broken.

Do not create fake state merely to reproduce the screenshots.
