# The switch specifically

The React source gives us an exact target:

```tsx

    width: 44
    height: 26
    borderRadius: 13
    padding: 3

    width: 20
    height: 20
```

So my previous 56×32 custom switch was also too large.

The Kotlin implementation should be:

```kotlin
@Composable
internal fun FocusFlowSwitch(
    checked: Boolean,
    onCheckedChange: (Boolean) -> Unit,
    modifier: Modifier = Modifier,
) {
    val thumbOffset by animateDpAsState(
        targetValue = if (checked) 18.dp else 0.dp,
        label = "focusFlowSwitch",
    )

    Box(
        modifier = modifier
            .size(44.dp, 26.dp)
            .clip(RoundedCornerShape(13.dp))
            .background(
                if (checked) BrandPrimary
                else RefBorder
            )
            .clickable {
                onCheckedChange(!checked)
            }
            .padding(3.dp),
    ) {
        Box(
            modifier = Modifier
                .offset(x = thumbOffset)
                .size(20.dp)
                .clip(CircleShape)
                .background(Color.White),
        )
    }
}
```

**That is the control I would want.**

No boundary.

No Material track.

No Material thumb.

No 56dp-wide switch.
