    This page checks the envelope and common task rules. FocusFlow is the final validator for every setting and may skip invalid tasks or ignore settings it does not import.

    Minimum envelope

    These are the essential fields. The app treats a missing version as version 1, but including it is clearer.

    {
  "kind": "FocusFlowBackupV1",
  "version": 1,
  "settings": {},
  "tasks": []
}

    Exported metadata

    FocusFlow’s exporter also writes timestamps, Android platform, preset summaries, counts, and sometimes appVersion. These are useful context; the importer’s main data is settings and tasks.

    Task records

    Each task is one object inside the top-level tasks array. Timestamps need an explicit offset, such as the UTC Z shown below.

    Required task fields

    • id — non-empty string; task IDs must be unique in the file.
    • title — non-blank string, up to 1,000 characters.
    • startTime, endTime, createdAt, updatedAt — ISO-8601 date-times with Z or an explicit UTC offset. End must not be before start.
    • durationMinutes — integer from 0 through 100,000.
    • status — scheduled, active, completed, skipped, or overdue.
    • priority — low, medium, high, or critical.

    Optional task fields

    • description — string or null; omitted descriptions become empty.
    • tags — array of strings; up to 100 tags per task, each at most 100 characters.
    • reminders — array of reminder objects with id, taskId, integer offsetMinutes, and type: pre-start, at-start, or post-start. Optional notifId can be a string or null.
    • color — string; omitted color defaults to #6366f1.
    • focusMode — boolean; omitted value defaults to false.
    • focusAllowedPackages — optional Android package-name array or null.

    Portable settings

    Names are case-sensitive camelCase. The app validates recognized values; invalid settings can be omitted with warnings. Start small and add only fields you need.

    UseRecognized setting keys and shapes
    Focus preferencesdarkMode (boolean), defaultDuration (5–480), pomodoroDuration (1–180), pomodoroBreak (1–60), keepFocusActiveUntilTaskEnd (boolean), autoRescheduleEnabled (boolean).
    App listsallowedInFocus, alwaysOnPackages, alwaysOnVpnPackages, focusToolPackages, launcherHiddenPackages, and launcherDockPackages are arrays of Android package names such as com.example.music.
    Blocking and allowancesblockedWords and overlayQuotes are string arrays. dailyAllowanceEntries, blockPresets, allowedAppPresets, recurringBlockSchedules, and greyoutSchedule are arrays of objects.
    Profile and launcheruserProfile supports fields including name, occupation, dailyGoalHours, wakeUpTime, sleepTime, focusGoals, chronotype, focusSessionLength, breakStyle, distractionTriggers, motivationStyle, and weeklyReviewDay. Times use HH:mm. launcherTheme is classic or glassy.
    ProtectionfocusMirrorVpnEnabled, launcherBlockUninstall, and launcherLockDuringStandalone are booleans. protectionMode must be standard or iron.

    Presets and daily allowances

    "blockPresets": [{
  "id": "social-apps",
  "name": "Social apps",
  "packages": ["com.example.social"]
}],
"dailyAllowanceEntries": [{
  "packageName": "com.example.video",
  "mode": "count",
  "countPerDay": 3,
  "dailyAllowanceMs": 0
}]

    Preset objects use id, name, and packages. Allowance modes are count, time_budget, or interval; the selected mode’s numeric fields should be included.

    Recurring schedule example

    "recurringBlockSchedules": [{
  "id": "evening",
  "name": "Evening block",
  "packages": ["com.example.social"],
  "days": [1, 3, 5],
  "startHour": 21,
  "startMin": 0,
  "endHour": 22,
  "endMin": 30,
  "enabled": true,
  "vpnEnabled": false,
  "vpnPackages": []
}]

    Hours are 0–23, minutes are 0–59, and days uses integer values 1–7. The app also exports derived greyoutSchedule windows.

    Not everything is portable

    FocusFlow deliberately leaves device-specific runtime state, active blocking state, notification toggles, onboarding/privacy flags, wallpaper URIs, and Defense PIN settings on the device. Adding those settings to a hand-written file will not restore them. Importing changes that weaken protected entries may require the destination device’s Defense PIN.

    What happens when you import

    A file passing this page’s checks is not applied immediately. FocusFlow stages it and shows a review screen before making changes.

    1 · Choose sectionsImport portable settings and block lists, tasks and reminders, or both.
    2 · Choose task behaviorMerge keeps existing tasks and skips matching IDs. Replace deletes current task rows first.
    3 · Review and confirmCheck counts and warnings. Replace is unavailable while a Focus Session is active; protection changes may prompt for a Defense PIN.
    • Portable settings overwrite matching imported fields; fields omitted from the file stay local.
    • Duplicate task IDs in the file make the backup unsafe to import. During merge, existing IDs are kept; conflicts can require Replace.
    • Invalid task records are skipped with warnings. A scheduled task whose end time is already past is imported as skipped.
    • Some device-only resources are not restored. Use the review screen to inspect warnings before confirming.

    Format limits and cautions

    These limits come from the Android V1 parser. Keep hand-written files small and standards-compliant.

    Parser limits

    • Maximum file size: 8 MiB of UTF-8.
    • Maximum JSON nesting depth: 12.
    • Maximum tasks: 20,000.
    • Maximum string length: 20,000 characters; task title limit: 1,000.
    • Duplicate JSON object keys are rejected. Do not add comments or trailing commas.

    Before importing

    • Keep an untouched copy of any backup before experimenting.
    • Use a JSON-aware editor and save as UTF-8 with the .focusflow extension.
    • Read the Android import preview. The app may report ignored settings or skipped tasks.
    • Replace mode is destructive to the existing task list. Choose it only when that is intended.
    Format reference: FocusFlow’s Kotlin V1 backup exporter, parser, settings adapter, and import review flow. This helper does not connect to the app, send data, or replace the app’s own import validation.
